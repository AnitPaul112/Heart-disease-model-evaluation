# Heart Disease Classification - Data Preprocessing & Model Evaluation

This repository contains a Jupyter Notebook that focuses on preprocessing heart disease data, applying two classification models, and evaluating their performance using standard metrics.

## 📌 Project Overview

The goal of this project is to:
- Preprocess the heart disease dataset for effective modeling.
- Apply two classification algorithms to predict the presence of heart disease.
- Evaluate the models using performance metrics such as accuracy, precision, recall, and F1-score.

## 🧪 Methods Used

- **Data Preprocessing**
  - Handling missing values
  - Encoding categorical features
  - Feature scaling (if applicable)

- **Classification Models**
  - Model 1: [Logistic Regression]
  - Model 2: [XGBoost]

- **Evaluation Metrics**
  - Accuracy
  - Precision
  - Recall
  - F1-score
  - Confusion Matrix
  - ROC
  - AUC
